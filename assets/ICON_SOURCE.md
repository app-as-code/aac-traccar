# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr), which provides ready-made logos for self-hosted applications.
No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/traccar.svg` | Default (used as `<img>` fallback) |
| `icon-light.svg` | `svg/traccar-dark.svg` | Dark-colored logo for light backgrounds |
| `icon-dark.svg` | `svg/traccar-light.svg` | Light-colored logo for dark backgrounds |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/traccar.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/traccar-dark.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/traccar-light.svg
